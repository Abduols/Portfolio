# Number Guessing Game

This is a simple number guessing game made with HTML, CSS and Javascript.

## How to Play

This game has a very few steps and easy to play.

1. The game generates a random number between 1-50 for the player to guess from.
2. You have 15 attempts to try and guess the right number after the games starts.
3. You are to enter your guess in the input field for the game to load and check your the number you input.
4. Then you get feedback when the number you choose is higher or lower than the correct number picked by the javascript. Saying "Too high, ..." or "Too low,..." .
5. The game ends if you win, by guessing the correct number within 15 attempts or when you fail to that, which means game Over.
6. When you win / Loss, You have reset the game using the "reset button"
   to play again.

## Features

- Random number generator
- Input field
- Submit/Reset button(by clicking the button or by pressing Enter on your keyboard)
- Win/ Loss conditions
- Attempt counter
- Responsive Design

## Technologies

- HTML5
- CSS
- Javascript
